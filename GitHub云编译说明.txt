LuaEngineUI 1.3.2 - GitHub Actions 云编译版

电脑不需要安装 Visual Studio。

使用：
1. GitHub 新建一个空仓库。
2. 把这个 ZIP 解压后的“文件夹里面所有内容”上传到仓库根目录。
   注意必须能直接看到：
     LuaEngineUI.sln
     .github/workflows/build.yml
3. 打开仓库顶部 Actions。
4. 左侧选择 “Build LuaEngineUI x64”。
5. 点击右侧 “Run workflow” -> “Run workflow”。
6. 等待任务完成。
7. 打开完成的任务，页面底部 Artifacts 下载：
     LuaEngineUI-1.3.2-x64
8. 解压得到 LuaEngineUI.dll。

测试：
- 此兼容分支基于旧 LuaEngineUI 的 D3D12 hook，所以先用 DX12。
- DLL 放到：
  Monster Hunter World\nativePC\plugins\LuaEngineUI.dll
- LuaEngine.dll 保持你已经确认可用的 1.3.2，不要降级。

如果 Actions 变红：
打开失败的 Build Release x64 或 Install dependencies 步骤，
复制最后约 50 行日志发给我，我直接按实际错误修改工程。
