GitHub 网页上传精简版

1. 新建 GitHub 空仓库。
2. 解压本 ZIP。
3. 在仓库 Add file -> Upload files。
4. 把解压后所有内容拖进去。
5. Commit changes。
6. Actions -> Build LuaEngineUI 1.3.2 -> Run workflow。
7. 成功后从 Artifacts 下载 LuaEngineUI-1.3.2-x64。

如果 GitHub 网页仍提示文件过多，请截图；本包已移除 sol/第三方源码等，依赖由 Actions 云端 vcpkg 下载。
如果 Actions 失败，把失败步骤最后 50 行日志发给我。
